# 后续功能计划：注册、产品目录与香港部署

更新日期：2026-10-06。本文记录后续开发的产品决策和验收标准，本次只归档计划，
不实现注册、产品选择或部署功能。

## 已确定的方向

- 第一版注册使用“昵称 + 密码 + 邀请码”，暂不使用邮箱或手机验证。
- 普通用户只能搜索并选择后台已发布的产品，不再维护数据源和字段映射。
- 产品搜索无结果时不保存记录，产品名旁用红字显示“暂时查不到该产品信息，请联系管理员。”
- 净值或依赖净值计算的字段缺失时显示 `/`，底层继续使用 `null`，不用零代替缺失值。
- 首选香港云服务器进行小范围试用；Cloudflare 是否启用由直连对比测试决定。

## 一、邀请码注册

### 用户流程

1. 用户在注册页输入昵称、密码、确认密码和邀请码。
2. 服务端验证昵称唯一性、密码强度和邀请码状态。
3. 创建已激活的普通用户，同一事务内消耗邀请码，然后跳转登录页。

### 接口和数据

- 新增注册页和 `POST /api/auth/register`。
- 昵称复用现有唯一用户名；新昵称允许中文、字母、数字及下划线，长度 2～32 字符。
- 密码长度 8～128 字符，继续使用 Argon2id、CSRF 和现有登录保护。
- `users.email` 改为可空，不创建伪造邮箱；现有账号和邮箱数据保持不变。
- 邀请码默认单次使用、7 天有效，数据库仅保存哈希。管理员通过 CLI 生成和撤销。
- 继续使用 `REGISTRATION_OPEN` 总开关；关闭时注册页和接口同时停用。
- 注册默认每 IP 每小时最多 3 次尝试，限流需在多进程间共享。
- 忘记密码暂由管理员核实身份后通过 CLI 重置；重置后撤销用户的旧会话。
- 新增登录后修改密码入口，修改前验证当前密码。

## 二、后台产品目录

### 管理员流程

1. 采集器将公开产品目录写入候选集。
2. 管理员核对发行机构、登记编码、产品代码、份额类别和币种。
3. 管理员创建或关联标准产品，审核采集映射，再将产品发布到用户可选目录。
4. 未核验的采集候选不直接开放给普通用户。

### 用户流程

- 用户按产品名或产品代码搜索本地目录。
- 候选项显示产品名、发行机构、产品代码、份额类别和币种，避免同名产品误选。
- 用户选定产品 ID 后才能保存交易；服务端再次校验产品已发布。
- 搜索无结果时只显示提示，不创建待匹配持仓或临时产品。
- 普通用户不再看到数据源 URL、字段映射、预览和审核入口，相关接口限管理员使用。

### 三种产品状态

| 状态 | 是否可保存 | 页面表现 |
|---|---:|---|
| 目录中无产品 | 否 | 产品名旁显示红字“暂时查不到该产品信息，请联系管理员。”，相关数值显示 `/` |
| 产品已发布但暂无行情 | 是 | 显示“暂无净值数据”，净值、市值和依赖行情的收益显示 `/` |
| 有历史行情但未及时更新 | 是 | 保留最近真实数值，显示净值日期和过期/不完整状态 |

已有持仓引用的产品停止发布后，仍可查看、赎回和纠错，但不再出现于新增交易的默认搜索结果。

## 三、香港部署与访问速度

### 试用部署

- 使用香港云服务器运行现有 Web、Worker、Scheduler 和 PostgreSQL 容器。
- 生产配置只公开 HTTPS 反向代理，PostgreSQL 不映射到公网。
- 启用安全 Cookie、生产密钥、日志、健康检查及每日备份，上线前执行一次恢复演练。
- 在目标服务器实测银行数据源可达性，采集不可用时不影响用户查看已入库数据。

### 性能验证

- 先移除 Google Fonts 外部依赖，使用系统字体或本地字体。
- 静态资源使用版本化长缓存和压缩；认证、持仓、收益和管理页明确设置私有或不缓存。
- 在同一香港源站对比 HTTPS 直连和 Cloudflare 代理，记录 TTFB、首屏时间、失败率和静态资源缓存命中率。
- 使用大陆移动网络和宽带各执行测试，只有代理结果稳定改善时才启用 Cloudflare。
- Cloudflare Tunnel 只作为可选接入方式，不将其视为备案或大陆加速方案。

## 实施顺序

1. 先收紧数据源权限，完成后台产品审核、发布状态和用户产品搜索。
2. 改造新增交易流程及缺失数据展示，确保缺失值不参与错误汇总。
3. 实现邀请码注册、管理员邀请码 CLI、修改密码和管理员重置密码。
4. 准备香港生产配置、备份与恢复流程，完成直连与 Cloudflare 对比测试。

## 验收标准

- 邀请码的有效、过期、撤销、重复和并发使用都有测试；注册关闭、重名和限流行为正确。
- 普通用户无法调用数据源和映射配置接口，用户数据仍相互隔离。
- 产品搜索覆盖中文名称、代码、同名不同份额、无结果、暂无行情和行情过期。
- 搜索无结果时指定红字文案和 `/` 正确显示，且无法绕过页面保存。
- 缺失行情不生成零净值、零市值或虚假收益，组合汇总保留不完整状态。
- 香港部署中数据库不对公网开放，HTTPS、采集、重启持久化和备份恢复验收通过。

## 本轮不实施

- 邮件或短信验证与自助找回密码。
- 自动保存或自动映射搜索不到的产品。
- 根据名称自动猜测发行机构、份额或映射关系。
- 在未实测前购买额外 CDN 或 Cloudflare 大陆网络服务。
- 新增银行适配器；先沿用现有建设银行目录和采集链路验证流程。
